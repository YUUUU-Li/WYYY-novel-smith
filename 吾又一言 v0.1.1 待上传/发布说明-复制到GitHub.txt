# 吾又一言 v0.1.1

长篇小说设定构思工作台。**纯本地**运行，不需要账号、不联网；数据是纯文本文件，一本小说就是一个能整包拷走的文件夹。

## 下载哪个

| 文件 | 适合谁 | 说明 |
|---|---|---|
| `吾又一言_0.1.1_x64-setup.exe` | **大多数人** | 安装版。装完开始菜单/桌面有图标，双击就是一个独立窗口 |
| `吾又一言-v0.1.1-免安装桌面版.zip` | 想免安装、但要真桌面窗口 | 解压后双击 `吾又一言.exe`。不经过浏览器、不需要 Node、不占端口 |
| `吾又一言-便携版-v0.1.1-win64.zip` | 系统里没有 WebView2、或想放 U 盘带走 | 解压后双击 `启动.vbs`。**已内置 Node 运行时**，走 Edge 的应用窗口 |

系统要求：Windows 10 / 11 x64。安装版与免安装版需要系统里有 WebView2 运行时（Win11 自带；Win10 一般随 Edge 已装）。便携版不需要。

## 这一版改了什么

- **桌面版的启动不会再被上一代残留拖死。** 之前 release 版会以 `0xC0000409` 静默退出，真实原因是 WebView2 报 `0x800700AA`（用户数据目录被上一次没退干净的 `msedgewebview2.exe` 占着），Tauri 建窗口失败后 panic，而 `panic = "abort"` 把它伪装成了"栈溢出"。
  现在启动时会先探测默认缓存目录能不能用：**被占就自动换一个新的**，并在 `crash.log` 里记一笔，程序照常打开。
- **单实例**：第二次双击只把已有窗口提到前面，不会开第二个进程（也就不会再制造出抢目录的两个实例）。
- **桌面版现在真的把稿子写成文件了。** 之前桌面版的「选择小说库文件夹」借的是浏览器那一套权限，而且每次启动都要重新点一次；现在弹的是 Windows 自带的选文件夹窗口，路径记在本地，**下次启动自动接着用**，读写直接走程序自己的文件层。
  顺带把「外部改动检测」也在桌面版接通了：你在记事本里改完某个 `.md` 保存，程序会发现，不会拿内存里的旧版本盖掉它。
  那条提示也拆成了两种：真的被改过，还是文件夹找不到了。后者不再给你「载入磁盘版本 / 保留当前版本」这两个都没用的按钮，而是直接让你重选文件夹。
- **崩溃不再无声**：启动失败会写日志到 `%LOCALAPPDATA%\com.novelstudio.desktop\crash.log`，并弹一个说人话的消息框。
- 发布版关掉了控制台黑窗；安装包只出 NSIS 一种（MSI 那一步的 WiX 在中文输出路径下会失败）。
- 便携版新增 `启动.vbs`（无黑框启动 + 应用窗口）与 `停止.vbs`；`启动.cmd` 保留作诊断用。
- **换了图标**：米色底、墨色「言」、朱点（由仓库里的 `logo.png` 生成）。安装版/免安装版的 exe、快捷方式、文件夹里看到的都是它；网页版的标签页图标、以及 `启动.vbs` 那个 Edge 应用窗口的图标也一起换了。

## 已知问题

1. **Windows SmartScreen 会提示"未知发布者"** —— 这个包没有代码签名证书。点"更多信息 → 仍要运行"即可，不是安装包坏了。
2. 万一启动仍失败（极少数环境）：任务管理器里结束所有 `msedgewebview2.exe` 再启动，或重启电脑；免安装版里附了 `重置界面缓存.cmd`。
3. 大纲的拖拽只支持同级重排，不支持跨层级拖动。
4. 事件量上到上千时，「全部事件」那张轴会变慢（目前没有虚拟化）；一两百个事件无压力。
5. **浏览器版和桌面版的内部存储是两套，互不相通。** 如果你此前一直在网页版里写、从没选过文件夹，直接换成桌面版会看到空的作品库。正确做法：先在网页版点「选择小说库文件夹」把稿子落成文件，再用桌面版选同一个文件夹。

## 数据存在哪

没选文件夹之前，稿子存在程序自己的内部存储里：关掉程序不会丢，但你看不到文件，也拷不走。

**强烈建议启动后点「作品库 → 选择小说库文件夹」**：桌面版弹的是 Windows 自带的窗口，选完就记住，下次启动自动接着用；之后每个条目就是一个 `.md` 文件、每本小说一个文件夹，可以随便备份、进 git、丢网盘。

## 从源码跑

```
npm install
npm run start      # 起本地服务器并打开浏览器
npm run check      # 类型检查 + 657 项单元测试
```

详见 README。
